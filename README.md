# Живой аквариум — Supabase Edition

Это версия без регистрации по электронной почте: сайт автоматически создаёт анонимную Supabase-сессию в браузере. Для подключения Android TV используются QR-код или шестизначный одноразовый код. Cloudflare D1/R2/Email Service и SMTP не нужны. Статические страницы публикуются через Netlify Free.

> **Важно о сохранности:** анонимная учётная запись привязана к данным сайта в текущем браузере. Пока браузер сохраняет свою сессию, аквариум будет открываться повторно. Если очистить данные сайта, потерять браузерный профиль или перейти на другой телефон, доступ к этому аквариуму может быть потерян. Не очищай данные сайта. Перенос/восстановление аквариума между телефонами в этой версии не реализован. Платные дополнения и платёжные данные не нужны для настройки, но бесплатные квоты провайдеров действуют.

## Что сохранено

- Русскоязычный адаптивный интерфейс телефона и страница аквариума для телевизора.
- Автоматическая анонимная сессия через Supabase Auth — без имени, пароля, электронной почты и писем.
- Личный аквариум пользователя: фон, скорость плавания и пузырьки.
- Фотографирование/выбор рисунка рыбки, удаление связанного с краями белого фона на устройстве и обрезка прозрачных полей.
- До 100 рыбок и 40 декораций на аквариум.
- Приватное файловое хранилище: изображения лежат в закрытом Supabase Storage bucket, а не в публичном каталоге сайта.
- Полноэкранный ТВ-экран, QR-код и одноразовый шестизначный код сопряжения на 10 минут. Для сопряжения не нужна регистрация по электронной почте.
- Телевизор получает краткосрочные подписанные ссылки на изображения и синхронизирует состояние с облаком; телефон после сопряжения может быть выключен.
- Инерция, плавное движение, отталкивание от границ и других рыб, наклон и деформация рисунка для имитации движения хвоста.

## Архитектура

- `public/` — статические страницы и клиентский JavaScript.
- `public/config.js` — публичные параметры Supabase. Здесь указываются Project URL и anon/publishable key. **Service role key сюда добавлять нельзя.**
- `supabase/migrations/0001_initial.sql` — таблицы PostgreSQL, Row Level Security, закрытое хранилище, лимиты коллекции и RPC для сопряжения.
- `supabase/functions/aquarium-tv/index.ts` — серверная функция для создания кода сопряжения и безопасной выдачи состояния аквариума телевизору.
- `netlify.toml` — публикация каталога `public/` и адрес `/tv`.

## Бесплатные сервисы

1. **Supabase Free** — Auth, PostgreSQL, приватное хранилище и Edge Function. В бесплатном тарифе действуют ограничения на объём базы/файлов, трафик и вызовы функций; проект может приостанавливаться после периода низкой активности. Следи за Usage в панели Supabase.
2. **Netlify Free** — только статические HTML/CSS/JS-файлы. Данные и фотографии не хранятся в Netlify.
3. **Почта не используется.** Внешний SMTP и настройка подтверждения e-mail не нужны. Включи анонимный вход в Supabase.

Официальные справки: [Supabase Anonymous Sign-Ins](https://supabase.com/docs/guides/auth/auth-anonymous), [Supabase Free и квоты](https://supabase.com/docs/guides/platform/billing-on-supabase), [Netlify](https://www.netlify.com/pricing/).

## Развёртывание с телефона

### Шаг 1. Создай проект Supabase

1. Открой [supabase.com](https://supabase.com/) в браузере телефона и создай проект на Free.
2. Выбери регион поближе к пользователям (например, европейский, если доступен).
3. Сохрани пароль базы данных в надёжном месте. Не отправляй его в чат и не добавляй в архив.
4. В панели проекта открой **SQL Editor → New query**.
5. Открой файл `supabase/migrations/0001_initial.sql` из архива, скопируй весь текст в SQL Editor и выполни его. В конце не должно быть ошибки. Этот SQL создаёт таблицы и закрытый bucket `fish-images` с правилами доступа.
6. Открой **Project Settings → API** (название раздела может немного отличаться). Скопируй Project URL и публичный `anon`/`publishable` key.
7. В файле `public/config.js` замени значения:

```js
window.AQUARIUM_CONFIG = {
  SUPABASE_URL: 'https://ТВОЙ_PROJECT_REF.supabase.co',
  SUPABASE_ANON_KEY: 'ТВОЙ_ПУБЛИЧНЫЙ_ANON_ИЛИ_PUBLISHABLE_KEY'
};
```

Это публичный ключ для браузера; безопасность обеспечивается RLS. **Никогда не вставляй `service_role`/secret key в `public/config.js`, HTML или JavaScript.**

### Шаг 2. Включи анонимный вход (без регистрации)

1. В панели Supabase открой **Authentication → Sign In / Providers** (название может немного отличаться).
2. Найди **Anonymous Sign-Ins / Anonymous Users** и включи анонимный вход.
3. Не нужно включать подтверждение e-mail, настраивать шаблоны писем или SMTP.
4. После публикации сайт сам создаст анонимную сессию при первом открытии. Повторные открытия в том же браузере используют сохранённую сессию.
5. Не нажимай «очистить данные сайта» в браузере и не удаляй данные приложения/браузера: в этой версии нет переноса или восстановления анонимного аквариума на другом устройстве.

QR-код и шестизначный код относятся к подключению телевизора к аквариуму, а не к переносу владельца на другой телефон.

### Шаг 3. Разверни Edge Function для ТВ

Эта функция необходима, чтобы телевизор мог сопрягаться без ввода пароля пользователя, а фотографии оставались в закрытом хранилище.

**Вариант A — через Supabase CLI в Termux** (если CLI поддерживается твоей версией Android/Termux):

```bash
pkg update
pkg install nodejs git
cd ПУТЬ_К_РАСПАКОВАННОМУ_ПРОЕКТУ
npx supabase login
npx supabase link --project-ref ТВОЙ_PROJECT_REF
npx supabase functions deploy aquarium-tv --no-verify-jwt
```

При запросе авторизации используй токен Supabase CLI. Не вставляй его в публичные файлы проекта.

**Вариант B — через редактор Edge Functions в панели Supabase (удобнее с телефона):** открой **Edge Functions → Deploy a new function → Via Editor**, создай функцию с именем `aquarium-tv`, перенеси в редактор содержимое `supabase/functions/aquarium-tv/index.ts` и нажми **Deploy function**. После публикации открой настройки функции и отключи **Verify JWT** для этой функции: она не использует пользовательскую сессию Supabase, а проверяет отдельный случайный токен ТВ. В `supabase/config.toml` это уже указано для CLI-развёртывания. Эта функция не возвращает данные аквариума без действительного токена сопряжённого устройства.

Функция использует стандартные серверные переменные `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY`, предоставляемые Supabase среде Edge Functions. Не копируй service-role key в сайт.

### Шаг 4. Опубликуй сайт на Netlify Free

Рекомендуемый способ — подключить репозиторий GitHub к Netlify. В репозитории должен быть весь проект, включая папку `public`, `netlify.toml` и `supabase/`.

1. Создай репозиторий GitHub и загрузи файлы проекта. Не загружай секреты или пароль базы данных.
2. Открой [Netlify](https://app.netlify.com/), зарегистрируйся и выбери добавление сайта из GitHub.
3. Выбери репозиторий. Каталог публикации — `public`; команда сборки не нужна.
4. После публикации Netlify выдаст адрес вида `https://имя-сайта.netlify.app`.
5. Вернись в Supabase **Authentication → URL Configuration**, укажи этот адрес как `Site URL` и добавь его в разрешённые Redirect URLs.
6. Проверь, что `public/config.js` содержит URL и публичный ключ именно твоего Supabase-проекта. Если меняешь файл после публикации, дождись повторного деплоя.

`netlify.toml` перенаправляет `/tv` на `tv.html`; отдельно открывать можно и `/tv.html`.

## Проверка перед запуском

1. Открой сайт по HTTPS на телефоне.
2. Открой сайт в обычной вкладке и убедись, что анонимная сессия создаётся автоматически без формы регистрации и без писем.
3. Войди, поменяй фон и настройки, обнови страницу и убедись, что значения сохранились.
4. Сфотографируй тестовый рисунок, проверь прозрачный фон, добавь рыбку. Обнови страницу и проверь, что рыбка и её изображение остались.
5. Открой `/tv` на телевизоре. Войди на телефоне в раздел «Подключение ТВ», введи код с телевизора или отсканируй QR.
6. Убедись, что рыбки появляются на телевизоре и продолжают плавать после выключения/закрытия телефона.
7. Проверь удаление рыбки и декораций. Открой сайт в отдельном профиле браузера: там должна создаться отдельная пустая сессия, не показывающая первый аквариум.
8. В Supabase проверь **Logs / Edge Functions / Usage**. Не публикуй скриншоты, где видны секретные ключи, токены или личные данные.

## Ограничения и безопасность

- В бесплатных тарифах есть квоты; большой объём фотографий или активная публичная аудитория могут потребовать оптимизации либо другого тарифа. Этот проект не должен автоматически включать платные услуги.
- Supabase Free может приостанавливать неактивные проекты. Если аквариум долго не открывали, проверь статус проекта в панели.
- Хранилище изображений закрытое. Временные подписанные ссылки для ТВ действуют 24 часа; при длительной непрерывной работе телевизор обновляет их примерно раз в 20 часов.
- Для настоящего публичного запуска стоит добавить страницу политики конфиденциальности, резервное копирование и дополнительное тестирование на реальных устройствах.
- Удаление белого фона алгоритмическое, не нейросетевое: белые детали, соединённые с краем фотографии, могут стать прозрачными.
- Физика хвоста универсальная и не определяет автоматически, где у конкретного рисунка голова и хвост.

## Проверка JavaScript

На компьютере или в Termux в корне проекта:

```bash
npm run check
```

Эта команда проверяет синтаксис клиентских JS-файлов. Она не заменяет проверку реального Supabase-проекта, анонимной авторизации и телевизора.
